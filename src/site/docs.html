Documentation

tlp-icons is a free, open-source icon library where every icon is animated. One small custom element, <tlp-icon>, works in plain HTML and in every framework.

6,000+ icons 34 categories 100% animated MIT license Works offline

Installation

npm

npm install tlp-icons

CDN (no build step)

Loads the element and fetches only the icon categories the page uses.

<script type="module" src="https://unpkg.com/tlp-icons/dist/tlp-icon.js"></script>

<tlp-icon name="bell"></tlp-icon>

Offline, one file

A classic script with every icon inside (about 2.2 MB). It works from file:// and without any network or module loader.

<script src="tlp-icons.all.js"></script>
<tlp-icon name="bell"></tlp-icon>

The file is at node_modules/tlp-icons/dist/tlp-icons.all.js. Copy it next to your page.

Frameworks

Import the element once at startup, then use <tlp-icon> in any template.

React

import 'tlp-icons/element';

export function SaveButton() {
  return (
    <button>
      <tlp-icon name="save" /> Save
    </button>
  );
}

React 19 supports custom elements directly. With TypeScript, declare the tag once:

// tlp-icon.d.ts
declare namespace JSX {
  interface IntrinsicElements {
    'tlp-icon': { name: string; size?: string | number; stroke?: string | number;
                  trigger?: 'hover' | 'loop' | 'click' | 'none'; duotone?: boolean | ''; flip?: 'rtl' | 'x' };
  }
}

Angular

// main.ts
import 'tlp-icons/element';

// any component
import { Component, CUSTOM_ELEMENTS_SCHEMA } from '@angular/core';

@Component({
  selector: 'app-toolbar',
  schemas: [CUSTOM_ELEMENTS_SCHEMA],
  template: `<button><tlp-icon name="bell"></tlp-icon> Alerts</button>`,
})
export class ToolbarComponent {}

Vue

// main.ts
import 'tlp-icons/element';

// vite.config.ts
vue({ template: { compilerOptions: { isCustomElement: tag => tag === 'tlp-icon' } } })
<template>
  <tlp-icon :name="done ? 'circle-check' : 'circle'" />
</template>

Svelte, Solid, Lit, plain JS

Import tlp-icons/element and use the tag. Custom elements work natively in all of these.

Styling

Icons use currentColor, so they take the text color of their parent. Theme them with CSS variables:

tlp-icon { --tlp-size: 20px; --tlp-stroke: 1.75; }
.danger  { color: #dc2626; }          /* icon color = text color */
.card    { --tlp-duo: .22; }           /* duotone fill strength (needs the duotone attribute or this variable) */
VariableDefaultMeaning
--tlp-size24pxIcon size.
--tlp-stroke2Stroke width.
--tlp-duo0 (.16 with duotone)Opacity of the duotone body fill.

The hover rule

Animations should help, not distract. So hovering decides which icon plays:

  1. Hovering an icon animates it.
  2. Hovering anything else walks up to the nearest element that holds exactly one icon (a button, a menu item, a link) and animates that icon.
  3. If it reaches an element with several icons first (a card, a menu, a table row), nothing animates.

An animation always plays to the end, even if the pointer leaves. Try it:

Hover this card's text: nothing moves, because it holds three icons.

JavaScript API

Element methods

const el = document.querySelector('tlp-icon');
el.play();                       // play once (returns false if it is already playing)
el.setAttribute('name', 'bell'); // swap the icon
el.addEventListener('tlp-ready', () => { /* svg rendered */ });

Raw data and SVG strings (Node, SSR, build tools)

import { icons, categories, aliases, getIcon, getSvg } from 'tlp-icons';

getSvg('bell');                                 // static SVG markup
getSvg('bell', { size: 32, stroke: 1.5, duotone: true });
getSvg('bell', { animated: true });             // motion baked in (load dist/tlp-icons.css)
getIcon('trash-2');                             // aliases resolve too
icons.bell;      // { svg, m: [[part, anim, dur, delay, origin?], ...] }
categories;      // [{ id, title, icon, color, count }]
Importing icons pulls in the whole set. In pages, prefer <tlp-icon>: it downloads one category at a time.

Runtime settings

import { config, run, register } from 'tlp-icons/element';

config.speed = 0.8;          // 0.6 by default (about 0.9 s per icon); higher = slower
run(svgElement);             // play any rendered icon svg
register({ 'my-logo': { svg: '<path class="p1" d="M4 12h16"/>', m: [['p1', 'draw', 900, 0]] } });

Animation library

Every choreography is built from these 34 animations. Entrances bring a part into place. Gestures move it and return exactly to rest. Hover a tile to see it.

All keyframes are prefixed tlp-, so they never clash with Tailwind's spin/bounce/pulse or your own CSS.

Accessibility and motion

  • Icons are decorative by default (aria-hidden="true"). When an icon carries meaning on its own, give it a role and a label: 
    <tlp-icon name="circle-alert" role="img" aria-label="Error"></tlp-icon>
  • When the user's system asks for less motion (prefers-reduced-motion), icons never animate.
  • Animations are short (0.9 s on average, 1.6 s at most), soft, and always end exactly at rest.

Right-to-left

Motion always follows the drawing: an arrow pointing right moves right. For RTL pages, mirror directional icons with flip="rtl". They flip only when an ancestor has dir="rtl", and their motion flips with them.

<html dir="rtl">
  <button><tlp-icon name="arrow-right" flip="rtl"></tlp-icon> التالي</button>

How the motion works

Each icon is split into its strokes and measured. Then, in order:

  1. Hand-made choreography, if the icon has one (in overrides/).
  2. Mechanics. Clock hands are found and split at the face centre. The minute hand sweeps and the hour hand advances, keeping its new position. Gears spin on their axle, and arrows move the way they point.
  3. Composites. file-plus, user-cog and circle-check animate as base + badge or container + glyph. -off icons draw their slash last.
  4. Keyword rules from config/rules.json: bells swing, trash lids lift, eyes blink, rain falls, cars drive...
  5. Fallback. The body fills, the outline draws, details follow, then a soft finishing gesture.

Custom choreography

Improve one icon by adding overrides/<name>.json. Tag the moving pieces with part classes (p1...p4), mark the main body with d for duotone, and list the steps:

{
  "name": "bell",
  "svg": "<path class=\"d p1\" d=\"M10.27 21a2 2 0 0 0 3.46 0\"/> ...",
  "motion": [
    { "part": "p1", "anim": "swing", "dur": 1400, "delay": 0, "origin": "12px 3px" },
    { "part": "p2", "anim": "swing", "dur": 1400, "delay": 90, "origin": "12px 3px" }
  ]
}

dur and delay are design milliseconds (the runtime multiplies them by speed). origin is a CSS keyword (top, bottom left...) or a pivot in the 24×24 grid like "12px 12px". To change many icons at once, edit a rule in config/rules.json.

Build from source

git clone https://github.com/Tamer-Mansour/tlp-icons
cd tlp-icons
npm run build          # offline: upstream/ + config/ + overrides/  ->  dist/ + site/
npm test               # offline test suite
npm run dev            # gallery at http://localhost:5173
npm run sync           # online: fetch the latest Lucide + Tabler, then rebuild
npm run setup:browser  # once, then: npm run test:browser
No dependencies to install. Everything after npm run sync works without internet.
